# Meena Mahal AC Auditorium

A modern, responsive website for **Meena Mahal AC Auditorium**, a luxury wedding and event venue located in **Sankarankovil, Tamil Nadu**.

The website helps visitors explore the auditorium, view available facilities and photos, learn about the venue, and contact the auditorium directly for booking enquiries.

## ✨ Features

* 🏛️ Modern auditorium landing page
* 📱 Fully responsive design for mobile, tablet, and desktop
* 🖼️ Auditorium and venue photo sections
* 📞 Direct booking enquiry through phone call
* 🌐 English and Tamil language support
* 🌓 Light and dark theme
* ✨ Smooth animations and transitions
* 📍 Contact and location information
* 🎨 Modern luxury-style user interface

## 📞 Booking

The website does not use an online booking calendar or booking database.

When a user clicks **Book Now**, a booking popup displays the auditorium's contact information with a **Call Now** option.

Users can directly contact the auditorium to check availability and make booking enquiries.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/manikandan151113/Meena-Mahal-AC-Auditorium.git
```

### 2. Open the project

```bash
cd Meena-Mahal-AC-Auditorium
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The website will be available on the local development server shown in the terminal.

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

The production files will be generated inside the `dist` folder.

To preview the production build:

```bash
npm run preview
```

## 🌐 Deployment

This project is a **static frontend application** and can be deployed using platforms such as Vercel.

The project is configured for deployment using:

```text
Build Command: npm run build
Output Directory: dist
```

## 🔐 Backend & Database

This project currently does **not** use:

* ❌ Backend server
* ❌ Database
* ❌ Admin panel
* ❌ Online booking calendar
* ❌ Online payment system
* ❌ External booking API

The website focuses on providing information about the auditorium and allowing visitors to contact the venue directly.
